# RHCSA Linux Administration Labs

Hands-on Linux System Administration and RHCSA (EX200) preparation using Red Hat Enterprise Linux 10.

## Objectives

- Develop practical Linux administration skills.
- Prepare for the Red Hat Certified System Administrator (RHCSA) exam.
- Practice real-world troubleshooting.
- Implement secure and persistent system configurations.
- Document technical decisions, commands and verification procedures.

## Lab Environment

| Component | Technology |
|---|---|
| Virtualization | Oracle VirtualBox |
| Operating System | RHEL 10 |
| Primary Server | rhcsa01 |
| Secondary Server | rhcsa02 |
| Version Control | Git / GitHub |

## Learning Methodology

20% theory and 80% hands-on practice.

Each lab follows:

1. Understand the concepts.
2. Explore the Linux environment.
3. Implement the requirements.
4. Verify the results.
5. Troubleshoot failures.
6. Document findings.

## Repository Organization

- `labs/` — Practical exercises organized by topic.
- `troubleshooting/` — Incident investigation and resolution.
- `challenges/` — Real-world administration scenarios.
- `mock-exams/` — RHCSA-style practical assessments.
